What this check covers

Checks include file structure, required values, dates, duplicate line IDs, line amounts and invoice totals.

Field lengths, timekeeper name format and reference classifications are checked. Ambiguous description sizes and numeric widths produce warnings.

Client guidelines and client-specific code lists are not checked here. Client code lists are available through the local CLI and library.

A result with no issues does not guarantee portal acceptance. Review the receiving client’s requirements before submission.

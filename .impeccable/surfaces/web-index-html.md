# Local invoice checker

Mode: Operate. Scope: web/index.html, styles.css and app.js. The approved task is a local browser checker with file selection, explanations and JSON export. User approval already covers implementation. Visual choices are reversible assumptions, not standing preferences.

## Direction contract

THESIS: A working review sheet pairs the selected invoice with its correction list. It avoids a marketing hero and dashboard metrics.

OWN-WORLD: Pale mineral white, evergreen controls, dark graphite type and restrained ochre/red issue states. Self-hosted Lato gives short headings and precise functional labels one voice. Only field identifiers and numeric values use monospace.

STORY: Choose one invoice, see the implemented checks, expand a finding, correct the source file, then check again. Files remain in the tab.

FIRST VIEWPORT: A compact wordmark tops a left-aligned title. A 340px input column sits beside a wider white review sheet. Empty results offer two explicitly synthetic examples. Findings expand in place to show field, location, correction and evidence.

FORM: Grounded candidate 4, the annotated professional journal index. seed:d772f78312d320e3. A code-led build. Candidate order: filing index, accounting ledger, legal reference marginalia, professional journal index, civic signage, technical standards typography, library accession register. The index translates into a clear list with contextual detail, not a literal paper costume.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Design review before implementation

The initial serif/cream proposal was too close to a generic marketing treatment. The revised single-family layout gives the invoice and corrections more space. UI/UX Pro Max's legal query offered Lato and accessible minimalism, which fit. Its marketing, badge and sales sections do not fit this task. A narrower tool query still suggested marketing sections. Those recommendations are excluded. Its explicit error-summary search supports visible inline errors and announced results.

## Challenger assessment

All six challengers lose audience identification and task clarity to the working review sheet. Streaming tiles hide textual corrections. Transit routes imply a journey that the task does not have. Monochrome marketing interleaves proof with claims instead of work. Acetate tabs introduce manual navigation with no need. Crouwel letter construction makes the typography the task. Exposure sheets obscure simultaneous comparisons.

Each declined system raises a discipline: streaming demands clear focus, transit demands location context, monochrome demands demonstrable claims, acetate demands ordered detail, Crouwel demands grid consistency, exposure sheets demand distinguishable states without color alone. No motifs or materials transfer.

## Constraints

No account, upload, history, external font request, telemetry or public deployment. Preserve bytes and original file. Show implemented-check limits. One file, up to 5 MB and 10,000 data records. Zero runtime dependencies. Native controls, responsive layout, focus visibility, reduced-motion support. Detailed results are paged to keep the interface usable.
